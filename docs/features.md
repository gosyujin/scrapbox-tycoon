# 機能の詳細

## 1. ヘッダーのアイコン群を右寄せ (`38adcfe`)

📖 参照リンク / 🔀 ランダム / ⚙️ 設定のアイコンを PC・スマホ共に右端に揃えたい
という要望。デスクトップでは隣接する検索ボックス (`quick-open-row`) の
`flex: 1` が結果的にこれを実現していたが、モバイル幅では `quick-open-row` が
自分の行に折り返すため、ブランド名の隣にアイコン群が来てしまっていた。
`.topbar nav { margin-left: auto; }` を追加し、幅に関わらずアイコン群自体を
行の右端に押し出す形にした。

> 後続の「9. 追加ボタン・検索フォームのフッター化」で `quick-open-row` は
> ヘッダーから外れた。`nav` の `margin-left: auto` はそのまま有効。

## 3. 同期ステータス履歴のコピー機能 (`e26e462`)

上記の調査で、「同期中のまま止まった」のようなユーザー体験を後から正確に
追うための材料が何もないことが分かった。`GitHubSyncStore.setStatus()` が
状態遷移の度に `{t, state, dirtyCount, lastError}` を localStorage
(`scrapbox_tycoon_sync_log_v1`, 直近 300 件) に追記するようにした。
**あえて localStorage に永続化**しているのは、リロードや `GitHubSyncStore`
インスタンスの再生成を跨いで残す必要があるため —— 問題が起きたその場で
デバッグできるとは限らない、という前提。

`SyncCapable.getStatusLogText()` でテキスト化し、設定画面に
「同期ログをコピー（デバッグ用）」ボタンを追加。バグ報告時にこれをそのまま
貼ってもらう想定。

## 5. ページ一覧に接続先リポジトリへのリンクと最終同期コミットを表示 (`8854425`)

デバッグ用に、ページ一覧上部のバッジを実リポジトリへのリンクにし、隣に
最終同期時点のコミット短縮 hash・時刻・未同期の変更があるときの
`[Modified]` を表示するようにした。`SyncStatus.lastSyncedCommitSha` を
新設し、`GitHubStore.getHeadCommitSha()` で毎回の同期成功後に HEAD を
読み直して埋める (push しなかった pull-only の同期でも更新される)。

## 6. 同期直後にPC/スマホの表示が古い内容へ「巻き戻る」問題 (`0709f2c`) — 副産物

**副産物:** 個別ページの画面にも、この店の最終同期コミット hash・時刻と
そのページ自身の `updated` を並べて表示する行を追加した (同期関連の不具合
調査で「このページの表示は本当に同期済みの内容か」をページを開いたまま
その場で確認できるように)。

## 8. 自分自身の push が「(sync conflict)」として別ページになる問題 — 競合時の UI・ページ削除ボタン

**それでも本物の競合が起きた場合の UI (`app.ts`):** `(sync conflict)` ページには
通常の「同名ページ」バナーより目立つ競合専用バナーを出し、元ページとの行単位
diff (`src/diff.ts`) の結果を「一致 / 不一致 (N 行の違い)」で表示、「違いを見る」
で +/- の差分を展開できる。一致なら「このコピーを削除」を主ボタンにし、統合
ボタンは出さない (同内容を統合すると全行が重複するため)。

個別ページ画面の下部に「このページを削除」ボタンを追加 (confirm あり)。
mousedown の preventDefault でエディタの blur=commit を先に走らせず、削除後に
遅れて届く `onChange` はフラグで無視する (削除直後にページが復活しないように)。

## 9. 追加ボタン・検索フォームを画面下のフッターに固定

gyazo-tycoon-viewer の `#sbar` と同じ構成に揃えた (hateb-tycoon / gyazo-tycoon
のスマホ版にも同じ指示を出している)。ヘッダーはブランド名 + アイコン群の
1 行だけになり、「+」ボタンと検索ボックス (`.quick-open-row`) は
`.bottombar` (`position: fixed; bottom: 0`) に入る。

- フッター高は `--footer-h` で固定 (51px + `env(safe-area-inset-bottom)`)。同期ステータス
  (`.status-bar`) と `.content` の下余白はこの値の分だけ持ち上げて重ならないようにする。
- iOS はキーボード表示時に visual viewport だけが縮み、fixed 要素がキーボードの
  下に隠れる。`trackKeyboardInset()` (`app.ts`) が覆われた高さを `--kb` に入れ、
  `.bottombar` が `translateY` で持ち上がる。フッターは毎回の render で作り直される
  ので、要素ではなく CSS 変数に持たせている。
- 検索ドロップダウンは上向きに開く。900px 以上では検索欄を最大 640px の中央寄せ。
- `cm-editor/mobile.ts` の `revealCaret()` はフッターの高さ分を可視領域から引く
  (キャレットがキーボードの上に載ったフッターの裏に隠れないように)。

## 10. 同期状態の見える化と自動取得 (decisions/09)

フッターの同期バッジは `SyncStatus.phase` の段階を、4 段のバー + 色 + 文言で出し分ける
(スマホは文言が省略されるので、色とスピナーだけでも状況が分かる):
待機中 (灰: まだ同期していない / 「未送信の変更: N件」= この端末がまだ送っていない) →
同期開始 (青・点滅: GitHub の HEAD を確認中) → 同期中 (青・スピナー: 受信中 / 送信中) →
同期完了 (緑: 確認時刻つき) / 競合あり (橙: マーカーが残っているページ/旧「(sync conflict)」コピーが N 件ある間) / エラー (赤)。
タップで即同期。前面表示中は 10 秒ごとに自動確認し、他端末の変更があればページ一覧を
自動で再描画する。バックグラウンドへ移る時は未送信の変更を即送信する。

## 11. ページエディタ (CodeMirror 6, decisions/11)

1 つの常時編集可能な文書で、**選択が触れている行だけ記法を展開**し、それ以外は描画状態
(リンクは `[` `]` なし、`[* x]` は太字、画像は表示、`code:` / `table:` はブロック表示)。
未フォーカス時は全行が描画状態。インデントは 1 文字 = 1 段のセルで、箇条書きの「・」と
折り返しのぶら下げ付き (展開しても位置はずれない)。

- **リンク**: 非アクティブ行のリンクは通常クリック (タップ) で遷移 (未作成は赤の破線、
  外部は緑 + ↗、存在しない `[title]` を開くと新規ページ)。アクティブ行では通常クリックは
  編集、Ctrl/⌘+クリックは常に遷移。遷移前に未保存の編集があれば先に commit する。
- **選択ポップアップ**: 文字を選ぶと `[ ]` / 太字 / 見出し / 斜体 / 取消 / 下線 / コード /
  ページ切り出しが出る。複数行選択は行ごとに囲む。囲んだ後も中身が選択されたままなので重ね掛けできる。
- **キー操作**: Enter = インデント引き継ぎ、Tab / Shift+Tab = 行のインデント (table: 内は
  タブ文字)、Backspace = 行頭の空白は 1 段ずつ、`[` の自動閉じ、Esc = blur (保存)、
  未フォーカス時の `i` / `o` (先頭 / 末尾に新規行で編集開始)。
- **アウトライン移動** (`src/outline.ts`): Ctrl+↑↓ = 行 (選択行) を 1 行ずつ入れ替え、
  Ctrl+←→ = 行のインデント/アウトデント。Alt+↑↓ = 段落 (行+配下) を兄弟と入れ替え、
  Alt+←→ = 段落ごとインデント/アウトデント。1 行目 (タイトル) は動かさず、その上にも動かさない。
- **スマホ**: タップした行がキーボード (と、その上に載る固定フッター) に隠れないよう、
  フォーカス時・visual viewport 変化時・入力時にスクロールで補正する。

## 12. 同期の競合の見え方と解消 (decisions/13)

別々の端末で同じページを変えた時は、行単位でマージされる。別の行の編集や末尾への追記は何も起きずに両方残る。
同じ行を別々に変えた時だけ、ページ内に両方の版が `<<<<<<<` / `=======` / `>>>>>>>` で残り、
ページの上に「同期の競合」バナーが出る (一覧のカードにも「⚠ 競合」)。バナーの各ブロックで
「先の版を残す / 後の版を残す / 両方残す」を押すだけで解消できる (マーカー行を手で消す必要はない)。
